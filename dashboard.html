    경과 · 임박 항목

      전체 태스크

      행을 클릭하면 상세 내용 · 진행 현황 원문이 펼쳐집니다.

      대분류
      #업무구분태스크담당자 / 요청기관우선상태처리예정일자최근 업데이트
      데이터 연동 — 열 때마다 구글시트(gviz API)에서 최신 데이터를 직접 읽습니다. 시트가 “링크가 있는 모든 사용자”로 공개되어 있어야 하며, 실패 시 제작 시점 스냅샷으로 자동 대체되고 상단 배지에 표시됩니다.
      상태 자동 반영 — 상태·우선순위·분류 목록을 코드에 고정하지 않고 시트 데이터에서 매번 새로 만듭니다. 새 상태값(예: 협의 필요, 확인 요청)이 생기면 KPI 카드·차트·필터·캘린더에 자동으로 추가되며, 처음 보는 값은 NEW 로 표시됩니다.
      마감 기준 — “처리예정일자” 열 값만 사용합니다. 상태가 완료/중단이거나 “처리일자”가 채워진 행은 경과·임박 집계에서 제외합니다.

      업무일지 자동 작성

      시트의 진행 현황 메모로 실적을, 처리예정일자·진행 중 업무·루틴으로 계획을 만듭니다. 각 항목 아래에는 진행현황 및 변동 사항이 줄마다 → 로 붙습니다. 기간만 정하면 ① 상위 / - 하위 / → 진행현황 형식으로 조립됩니다.

      미리보기

      실적 행과 계획 행을 위·아래로 나누되 같은 양식으로 적습니다. 표 전체를 복사해 엑셀·구글시트 첫 셀에 붙여넣으면 셀 안 줄바꿈까지 그대로 들어갑니다.

      구분업무명분류명업무내용

      다음 14일 루틴 부하

      각 루틴의 반복 주기를 펼쳐 날짜별 건수를 계산했습니다. 칸에 마우스를 올리면 그 날 할 일이 보입니다.

      루틴 인식 방법 — 시트 M열(반복 주기) 에 값이 있으면 루틴 업무로 봅니다. 매일 · 매주 월 · 매주 화,금 · 매월 5일 · 매월 말일 · 매분기 · 매년 3/1 · 10일마다 형식을 인식합니다.
      다음 예정일 — N열(최근 수행일) 에 주기를 더해 자동 계산합니다. 별도의 예정일 열을 두지 않아 두 값이 어긋날 일이 없습니다. N열이 비어 있으면 미실행으로 표시합니다.
      운영 방법 — 루틴을 한 번 처리할 때마다 N열 날짜만 오늘로 바꿔 주세요. 다음 예정일이 자동으로 밀립니다.
      지연 판정 제외 — 반복 루틴은 지연으로 집계하지 않습니다. 상단 지연 · 임박 지표는 처리예정일자만 보고, 루틴은 이 탭과 캘린더에서 일정으로만 표시됩니다.

      루틴 메모 — 반복되는 일은 캘린더에 뿌리지 않고 여기에 적어 둡니다

      시트 반복주기 열에 값이 있는 업무입니다. 지연으로 집계하지 않습니다.

      날짜를 선택하세요

      캘린더의 날짜를 클릭하면 해당 일자의 태스크가 여기에 표시됩니다. 항목을 누르면 상세가 열립니다.
